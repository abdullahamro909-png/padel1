# RPK Padel Scoring App for Xiaomi Smart Band 10

## How to Compile to `.rpk`:
1. Download and install [Xiaomi AIoT-IDE](https://iot.mi.com/vela/quickapp/en/guide/).
2. Open Xiaomi AIoT-IDE and select **Import Project** or create a new **Xiaomi Vela JS / Wearable** project.
3. Replace the project's `manifest.json` and `src/pages/Index/index.ux` with the files in this directory.
4. Click **Build > Produce RPK Package** in the IDE menu.
5. The compiled file `com.rpk.padelscoring.rpk` will be generated in the `dist/` folder.
